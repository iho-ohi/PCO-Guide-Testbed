
# Introduction

This testbed contains materials developed by a collaboration of all PCO Initiatives and related IMO NGO’s to allow ports to share Nautical and Operational Data based on IHO and IMO Standards. The main asset of this testbed are two APIs, the <a href="https://github.com/iho-ohi/PCO-Guide-Testbed/tree/main/nautical-data">Nautical Data API</a> and the <a href="https://github.com/iho-ohi/PCO-Guide-Testbed/tree/main/operational-data">Operational Data API</a>, especially designed to enable such tests. This testbed and its content are property of the Port of Rotterdam under the custodianship of IHO’s Nautical Information Provision Working Group (NIPWG).
